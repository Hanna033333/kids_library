책자리 (Checkjari) UX Flow Map

로컬에서 한눈에 확인하는 사용자 여정 (User Journey & Navigation Map)

🚀 실제 서비스 접속 🎨 UI 시스템 가이드
Flow 01

큐레이션 발견 ➔ 도서 상세 탐색 여정

핵심 Value Proposition
STEP 1 / (홈 피드)

홈 화면 & 큐레이션 섹션

- 2단 계층 서브/메인 타이틀
- 7일 주기 자동 순차 큐레이션
- 도서관 미지정 시 큐레이션에 집중

👉 액션: '더보기' 클릭 ➔ 전체 목록 / 책 카드 클릭 ➔ 상세
STEP 2 /books?curation=...

큐레이션 전체 목록

- 7-Book Rule: 홈 7권 상단 고정
- ㄱㄴㄷ 오름차순 기본 정렬
- 연령 필터 및 큐레이션 태그 매칭

👉 액션: 도서 클릭 ➔ 상세 진입
STEP 3 /book/[id]

도서 상세 & 2단 추천

- 도서 기본 정보 & 줄거리
- 1순위: 연령별 인기 추천 (7권)
- 2순위: 동일 태그 추천 (7권)
- Smart Back 버튼으로 이탈 방지

👉 액션: 북마크 / 도서관 소장 상태 확인 / 뒤로가기
Flow 02

도서 검색 & 검색 결과 0건 폴백(Empty State)

Zero-Result Retention
START SearchBar

검색어 입력 & 필터링

- 상단 언더라인 SearchBar
- 제목/저자/키워드 통합 검색
- 연령 필터 분기 처리

BRANCH A 결과 ≥ 1건

검색 결과 목록

- 매칭된 도서 카드 수직 리스트
- 선호 도서관 설정 시 실시간 대출 배지 표시

BRANCH B (핵심) 결과 0건 (Empty)

추천 도서 폴백 노출

- "조건에 맞는 책이 없지만 이 책은 어떨까요?"
- 연령 선택 시: 연령별 전국 인기 8권
- 일반 검색 실패 시: 전체 전국 인기 8권

🎯 유저 이탈을 100% 방지하고 탐색 연장!
Flow 03

자주 가는 도서관 선택 & 실시간 대출 가능 확인

실용주의 양육자 페르소나
STEP 1 LibrarySelector

도서관 선택 바텀시트

- 하단 고정 슬라이드업 바텀시트
- 6자리 정식 정보나루 공공도서관 검색
- 선호 도서관 1차 등록

STEP 2 LibraryContext

로그인 조건부 조인 (Batch)

- 비로그인/미설정: 도서관 쿼리 생략 (초고속)
- 로그인/설정완료: 조건부 DB 쿼리 실행
- React Query 캐시 키 분리 (`!!user`)

STEP 3 BookCard / BookItem

청구기호 & 대출 배지

- 청구기호: 주황 `#F59E0B`
- 대출가능: 초록 `#059669` / `#ECFDF5`
- 미소장: 회색 `#6B7280` / `#F3F4F6`

Flow 04

회원가입 ➔ 온보딩 팝업 ➔ 나만의 라이브러리

User Conversion & Retention

가입 유도 팝업

2. Kakao OAuth

카카오 간편 가입

3. SignupWelcomeModal

웰컴 온보딩 팝업

가입 축하 & 서비스 핵심 혜택 안내

4. /my-library & /my-page

북마크 & 설정 관리

찜한 그림책 목록 & 자주 가는 도서관 관리

Flow 05

외부 SNS 유입 ➔ 스마트 뒤로가기(Smart Back Route)

Smart Back Route
EXTERNAL Threads / Naver Blog

스레드 / 블로그 유입

- UTM 파라미터 기반 추적
- 단축링크 `/c/[tag]` ➔ 컬렉션 페이지로 자동 전환

LANDING HistoryTracker

다이렉트 랜딩

- 외부 유입 시 브라우저 히스토리 1개 감지
- `sessionStorage` 세션 히스토리 추적

SMART BACK BackButton

홈(`/`) 피드 자동 폴백

- 이전 이력 없으면 뒤로가기 클릭 시 홈(`/`)으로 안전 이동
- 서비스 이탈 방지 & 탐색 전환율 극대화
