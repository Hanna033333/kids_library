# 네이버 블로그 마케팅 포스팅 및 원고 최적화 가이드

## 🎯 개요
이 스킬 가이드는 네이버 블로그에 포스팅할 큐레이션 원고를 AI로 자동 생성하거나 직접 작성할 때, **C-Rank / DIA+ 검색 상위 노출**과 **모바일 체류 시간(Dwell Time) 극대화**를 위해 반드시 지켜야 할 마케팅 및 레이아웃 표준을 정의합니다.

---

## 📱 스마트에디터 ONE 호환 순수 텍스트 3단 구조 (최중요)
네이버 블로그 에디터(SmartEditor ONE)는 마크다운(`###`, `**`, `---`, `![]()`, `[]()`) 문법을 지원하지 않습니다. 따라서 원고는 마크다운 특수기호가 전혀 없는 **순수 텍스트(Plain Text)** 형태로 아래 3단 구조를 엄격히 분리하여 제공합니다.

1. **`=== 네이버 블로그 제목 ===`**: 검색 메인 키워드 + 클릭 후킹 문구 + 도서 수 + (도서관 대출 팁) 순수 텍스트 1줄
2. **`=== 네이버 블로그 본문 ===`**: 1인칭 공감 육아 에피소드 ➔ 1번 도서로 직진 ➔ 5권 상세 소개 ➔ 창작자 소개 및 도서관 대출 링크
3. **`=== 네이버 블로그 태그 ===`**: 공백 구분 해시태그 10개

---

## 📱 모바일 가독성 최적화 개행 표준
네이버 블로그 독자의 80% 이상은 모바일 기기로 본문을 읽습니다. 모바일 화면에서 문장이 3줄 이상 연속으로 노출되면 가독성이 극도로 저하되고 피로감을 주게 됩니다.

1. **의미 단위의 강제 줄바꿈 (엔터)**: 쉼표(,)나 논리적 호흡 단위에 따라 과감하게 줄바꿈을 적용합니다.
2. **짧은 문단 구성 (1~2줄 단위)**: 1~2줄 단위로 작성한 후 반드시 빈 줄을 두어 여백을 시원하게 확보합니다.

## 🖼️ 1080x1080 독창적 카드뉴스 이미지 5장 연동 (C-Rank/DIA+ 극대화)
- **네이버 유사 이미지 페널티 차단**: 일반 서점 표지는 중복 이미지로 판정되므로, 백엔드에서 자동 생성된 **1080x1080 고화질 독창적 카드뉴스 이미지 5장**(`backend/output/blog_posts/images/{tag}/card_1.png ~ card_5.png`)을 본문 각 도서 위치에 첨부합니다.
- **대표 썸네일 설정**: 검색 뷰(VIEW) 탭에서의 클릭률(CTR)을 극대화하기 위해 **1번 도서 카드뉴스 이미지를 블로그 [대표 이미지]**로 지정합니다.
- **텍스트 어절 안전 트리밍**: 카드 내부 설명글은 HTML 엔티티를 유니코드 꺾쇠(`〈`, `〉`)로 변환하고, 어절(공백) 단위 및 완성된 문장 종결(55~65자)로 다듬어 글자가 깨지거나 잘리지 않도록 유지합니다.

## 💡 스토리텔링 및 책자리 크리에이터 포지셔닝 원칙
1. **자녀 페르소나 (6세 외동 아이 한 명)**: 원고 작성 시 다자녀(첫째, 둘째, 두 아이 등) 설정은 절대 금지하며, 반드시 **"6살 아이 한 명"**을 키우는 실전 육아맘의 1인칭 시점으로 작성합니다.
2. **강의식 체크리스트 상자 배제**: 글의 몰입도를 방해하는 뜬금없는 꿀팁 상자를 넣지 않고, 자연스러운 1인칭 육아 고민 공감 후 바로 1번 도서 추천으로 연결합니다.
3. **창작자 진정성 강조**: 외부 유저 흉내(`책자리 애용해요`) 대신, *"아이들 책 찾기가 너무 불편해서 직접 '책자리(checkjari.com)'라는 서비스를 만들었어요"*라는 크리에이터 포지셔닝으로 신뢰도를 극대화합니다.
4. **허위 수식어 금지**: `@육아맘닉네임`, `1위 인플루언서` 같은 가공의 타이틀을 절대 사용하지 않습니다.
