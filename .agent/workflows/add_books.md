# 📚 도서 데이터 추가 및 보강 워크플로우 (Add & Update Books)

이 워크플로우는 새로운 큐레이션 도서(예: 여름방학 추천도서 등) 목록이 수집되었을 때, 알라딘 API 및 데이터베이스 보강을 거쳐 서비스 화면에 카테고리와 샵(#) 테마 태그 뱃지까지 안전하게 노출시키는 표준 절차입니다.

---

## 📋 신규 도서 추가 6단계 프로세스

### Step 1. 도서명 및 연령대(Age) 기본 매핑
1. **목록 확보**: 기획안이나 블로그 링크 등에서 도서 리스트를 추출합니다.
2. **연령대(Age) 매핑 표준**:
   - 도서의 발달 단계에 적합한 연령 표시를 표준 문자열(예: `'유아'`, `'3세부터'`, `'5세부터'`, `'7세부터'`, `'9세부터'`)로 정의합니다.
   - **초등 연령 표준**: 초등 1~6학년 대상 도서는 프론트엔드 연령 필터 탭에서 **'8~12세'**에 일관되게 표시되도록 DB `age` 컬럼의 값을 **`'9세부터'`**로 통일하여 매핑합니다.

### Step 2. 알라딘 API를 통한 메타데이터 및 카테고리 수집
1. **부제 Trimming**: 검색 성공률을 극대화하기 위해, 원본 제목에서 부제(예: `- 한옥`, `: 식량위기` 등)를 잘라낸 핵심 제목으로 알라딘 TTB API 검색을 수행합니다.
2. **장르/카테고리 매핑**:
   - 알라딘 분류 정보(예: `국내도서>어린이>동화/명작/고전>외국창작동화`)를 읽어와, 서비스 표준 카테고리(`동화`, `그림책`, `과학`, `사회`, `전통`, `예술` 등)로 매핑합니다.
   - API가 잡지 못하거나 잘못 매핑한 특수 도서들은 `manual_mappings` 딕셔너리를 두어 명시적으로 강제 보정합니다.
3. **임시 스크립트 격리**: 
   - 데이터 가공 및 업데이트를 수행하는 임시 파이썬 스크립트는 프로젝트 루트가 아닌 **`.gemini/antigravity-ide/scratch/`** 디렉토리에 격리 생성하여 메인 영역의 오염을 방지합니다.

### Step 3. 샵(#) 감정/발달 테마 태그 매핑 및 보강
1. **테마 분석**: 도서의 소개글과 줄거리를 분석하여, 서비스의 핵심 태그(예: `#생명존중`, `#판타지`, `#장애`, `#우정`, `#가족사랑`, `#자연관찰` 등)를 매핑합니다.
2. **태그 필드 구조화**:
   - `curation_tag` 컬럼에 들어갈 최종 값은 `"큐레이션식별자,#태그1,#태그2"` 형태(쉼표 구분)로 작성합니다.
   - (예: `여름방학2026,#장애,#우주,#과학,#자존감`)
3. **태그 접두사 보정**: 샵(`#`) 기호가 누락되거나 이중 해시가 생기지 않도록 데이터 정제 필터를 거쳐 저장합니다.

### Step 4. Supabase DB 적재 및 확장 (Upsert)
1. **ISBN 중복 체크**: 
   - 신규 도서 적재 시 반드시 ISBN(13자리) 기준 중복 여부를 먼저 조회합니다.
2. **데이터 병합 정책**:
   - 이미 존재하는 도서인 경우, 기존의 `curation_tag` 데이터를 지우지 않고 쉼표로 이어 붙여 확장(Update)합니다.
   - 존재하지 않는 도서인 경우 신규 행으로 등록(Insert)합니다.

### Step 5. Next.js 캐시 초기화 및 프론트엔드 검증
1. **로컬 Next.js 캐시 제거**:
   - DB 업데이트 후, 서버 컴포넌트 데이터 캐싱으로 인해 화면에 `category: null` 이나 태그 누락이 발생할 수 있습니다.
   - 터미널에서 다음 명령어로 로컬 캐시를 완전히 삭제합니다:
     ```bash
     rm -rf frontend/.next
     ```
2. **개발 서버 재기동 및 검증**:
   - Next.js 개발 서버(`npm run dev`)를 재부팅하여 홈 화면 카드 위와 책 상세 화면에 카테고리 뱃지 및 샵(#) 테마 태그 뱃지가 100% 정상 노출되는지 최종 검수합니다.

### Step 6. 검색 엔진 최적화 (SEO) 및 사이트맵 갱신
1. **정적 빌드 라우팅 설정 (`generateStaticParams`)**:
   - 새로 추가된 큐레이션 슬러그가 빌드 시 정적 HTML(SSG)로 사전 생성되도록 `frontend/app/collections/curation/[tag]/page.tsx` 내 `generateStaticParams()` 의 `specialCurations` 배열에 추가합니다.
2. **맞춤 메타데이터 설정 (`generateMetadata`)**:
   - 해당 큐레이션 슬러그 진입 시, 전용 메타 타이틀(Title), 설명(Description), 키워드(Keywords)가 적용되도록 `generateMetadata()` 내 분기 처리를 작성합니다.
3. **라우팅 유효성 검사 등록**:
   - 큐레이션 접속 시 404 에러로 튕겨 나가는 것을 막기 위해, `CurationPage` 컴포넌트의 `isKnownCuration` 조건 및 `SPECIAL_TAGS` 쿼리 필터 목록에 해당 슬러그를 반드시 등록합니다.
4. **구글 사이트맵 (`sitemap.xml`) 등록**:
   - 검색 로봇의 지속적인 색인(Indexing) 수집을 보장하기 위해 `frontend/app/sitemap.ts` 내 `specialCurations` 목록에 신규 큐레이션 슬러그를 추가합니다.
