# 📢 /notice 서비스 업데이트 공지 작성 & 검수 & 배포 워크플로우

이 워크플로우는 사용자가 서비스 기능 업데이트를 완료했을 때, **업데이트 항목을 전달받아 AI가 공지사항 초안을 작성하고 사용자에게 먼저 검수를 받은 후, 승인 시 노션 발행 및 프론트엔드 연결**을 진행하는 대화형 워크플로우입니다.

---

## 🔄 워크플로우 단계 (3-Step Interactive Process)

```
[1. 업데이트 항목 확인 (최근 배포 내역 자동 조회 또는 직접 입력)]
  - 별도 입력이 없거나 /notice 단독 호출 시: 에이전트가 `git log -n 10` 등을 통해 최근 상용 배포 내역 자동 파악
  - 사용자가 내용을 직접 전달한 경우: 해당 업데이트 내역 우선 반영
       ⬇
[2. AI 초안 작성 & 사용자 검수 (Review)]
  - AI: 3040 부모 타겟 공지문 초안(제목/요약/개선점/이용팁)을 채팅창에 미리보기로 제시
  - AI: "이 내용으로 노션에 올리고 프론트에 연결할까요? 수정할 부분이 있으신가요?"
       ⬇
[3. 사용자 승인(OK) ➔ 노션 발행 및 프론트 연결]
  - 사용자: "OK" (또는 "OOO 내용 좀 더 보강해줘")
  - AI: Notion API 호출해 '책자리' 페이지에 발행 ➔ `frontend/shared/latest_notice.json` 동기화 ➔ 최종 링크 안내
```

---

## 🛠️ [Step 1] 업데이트 항목 확인 (최근 상용 배포 자동 참조)

1. **내용 미지정 시 (기본 동작)**:
   - 사용자가 `/notice` 또는 `/notice_notion`만 입력하거나 "최근 배포 내용 보고 써줘"라고 요청한 경우, **에이전트가 `git log -n 10` 및 최근 상용 배포 커밋 내역을 직접 조회**하여 신규 기능/개선점/UI 변경 사항을 파악하고 요약합니다.
2. **내용 직접 지정 시**:
   - 사용자가 `/notice [내용]` 형태로 특정 변경 사항을 전달한 경우 해당 내용을 우선 반영합니다.

* *직접 입력 예시*:
  > `/notice 분당/수정/중원구 도서관 청구기호 연동 및 대출상태 실시간 조회 추가`

---

## 📝 [Step 2] 공지사항 초안 작성 및 검수 요청 (AI 에이전트 행동)

에이전트는 백엔드 스크립트의 초안 생성 로직(`generate_notice_content_with_gemini`)을 활용하거나 직접 공지문 초안을 작성하여 **채팅창에 아래 양식으로 검수 요청**을 출력합니다.

```markdown
### 📋 작성된 공지사항 초안

* **📌 제목**: {공지 제목 (날짜)}
* **💡 핵심 요약**: {부모님이 10초 만에 이해하는 요약 콜아웃 문구}

#### ✨ 어떤 점이 새로워졌나요?
* **{개선점 1}**: {상세 설명}
* **{개선점 2}**: {상세 설명}

#### 📖 이렇게 이용해 보세요!
* 1. {이용 팁 1}
* 2. {이용 팁 2}

#### 💌 마무리 인사
> {따뜻하고 다정한 감사 인사}

---
👉 **이 내용으로 노션에 등록하고 서비스에 연결할까요?** (수정하고 싶은 문구가 있다면 말씀해 주세요!)
```

---

## 🚀 [Step 3] 사용자 승인(OK) 시 노션 발행 및 프론트엔드 연결

사용자가 "OK", "좋아", "올려줘" 등으로 승인하면 다음 작업을 순차 실행합니다:

1. **노션(Notion) API 페이지 발행**:
   - `책자리` 부모 페이지(`2e4939f0-03ba-807d-9580-c056baacf0fa`) 하위에 새 페이지로 발행
2. **프론트엔드 데이터 동기화**:
   - `frontend/shared/latest_notice.json` 파일에 `title`, `url`, `published_at`, `date_label` 기록
3. **최종 결과 보고**:
   - 발행된 노션 개별 페이지 URL과 서비스 반영 결과를 안내
