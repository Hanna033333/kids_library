## 📝 기록 가이드
1. `/deploy-prod` 완료 직후 위 표의 최상단에 1행을 추가합니다.
2. Notion 칸반보드의 해당 카드도 아래 명령으로 `✅ 완료` 상태로 전환하고 `배포일`을 기록합니다:
   ```bash
   ./backend/venv/bin/python backend/scripts/notion_kanban.py update \
     --title "<과제 키워드>" --status "✅ 완료" --deployed-at "YYYY-MM-DD"
   ```
3. 배포 후 14일간 매주 월요일 텔레그램 리포트와 Notion `📊 주간 지표 트래커`에 자동 노출되어 성과를 추적할 수 있습니다.
