# 책자리 페이지별 기능 명세서 (`docs/pages/`)

책자리의 모든 화면별 **현재 구현된 기능(As-Is)**과 **수정/추가 요청(Draft)**을 한곳에서 관리하는 기능 지도입니다.

---

## 페이지 목차

| 문서 | 대상 라우트 | 핵심 역할 |
| :--- | :--- | :--- |
| [_common.md](./_common.md) | 전역 공통, `/intro`, `/c/[tag]`, `/terms`, `/privacy`, `/marketing`, 404 | 공통 헤더/푸터, 스마트 뒤로가기, 도서관 선택기, 온보딩/로그인 모달, 단축 링크 |
| [home.md](./home.md) | `/` | 스포트라이트 배너, 주간 AI 큐레이션, 50+ 테마 처방전, 교과서·칼데콧·연구회 섹션 |
| [books.md](./books.md) | `/books`, `/collections/*`, `/caldecott` | 도서 검색, 연령/학년 필터, 큐레이션 허브 및 랜딩 목록, 실시간 대출/찜 연동 |
| [book_detail.md](./book_detail.md) | `/book/[id]` | 도서 상세 정보, 실시간 대출/청구기호, 찜/공유/구매, 리뷰 CRUD, 4단 추천 슬라이더 |
| [my_library.md](./my_library.md) | `/my-library` | 찜한 도서 목록, 선택 도서관 대출 가능 권수 요약, 목록 텍스트 공유 |
| [my_page.md](./my_page.md) | `/my-page` | 프로필/닉네임, 내 도서관, 우리 아이 연령대 설정, 내 책장 미리보기, 로그아웃/회원 탈퇴 |

---

## 협업 워크플로우 (4단계)

1. **초안 작성 (사용자)**: 변경하고 싶은 페이지 `.md`의 `## 2. 수정/추가 요청 (Draft)` 영역에 원하는 내용을 편하게 메모
2. **검토 요청**: `"book_detail.md에 추가한 거 검토해줘"`처럼 에이전트에게 검토 요청
3. **AI 검토 & 합의**: 기존 기능 충돌, 모바일 UX, 엣지 케이스, 질문 사항 정리 후 합의
4. **구현 & 자동 동기화**: 코드 구현 완료 시 에이전트가 `Draft` 항목을 `## 1. 현재 구현된 기능 (As-Is)`으로 정리·반영
