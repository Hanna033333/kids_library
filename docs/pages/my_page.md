# 마이 페이지 (`/my-page`)

> 파일: `app/my-page/page.tsx`, `app/my-page/MyPageClient.tsx`
> 렌더링: Server 래퍼 + Client Component (`'use client'`), 비로그인 접근 시 `/` 리다이렉트

---

## 1. 현재 구현된 기능 (As-Is)

### 1-1. 메인 화면 (`currentView === 'main'`)
1. **헤더 (`PageHeader`)**: 타이틀 `"마이 페이지"`, `showHome=true`
2. **프로필 카드**: 이니셜 원형 아바타, 닉네임(미설정 시 랜덤 자동 생성) + 수정 연필 버튼, 이메일
   - **닉네임 변경 모달**: 공백 자동 제거, 2~10자 한글·영문·숫자, 300ms 디바운스 중복 검사(`GET /api/auth/check-nickname`), 저장 시 `PATCH /api/auth/me`
3. **내 도서관 카드**: `LibrarySelector` (`?action=select-library` 쿼리 진입 시 자동 오픈)
4. **우리 아이 연령대 카드**: `0~3세`, `4~7세`, `8~12세`, `13세 이상` 4개 토글 버튼 (재클릭 시 해제, 홈 큐레이션 및 도서 목록에 맞춤 적용)
5. **내 책장 미리보기 카드**: `"저장 N권"` + `/my-library` 이동 화살표(`>`), 최대 6권 미니 표지 가로 스크롤 (0권 시 `"책 둘러보기"` 버튼)
6. **하단 액션 행**: 좌측 `"회원 탈퇴"` / 우측 `"로그아웃"`
   - 로그아웃 시 `sessionStorage('showLogoutToast', 'true')` 저장 + `signOut()` + `/` 이동

### 1-2. 회원 탈퇴 STEP 1 (`delete-notice`)
- 헤더 타이틀 `"회원 탈퇴"` (뒤로가기 시 `main` 복귀)
- `{닉네임}의 책자리` / 현재 찜한 도서 권수 표시
- 탈퇴 유의사항 안내 + 동의 체크박스 + `"나중에 하기"` / `"계속 진행하기"`

### 1-3. 회원 탈퇴 STEP 2 (`delete-reason`)
- 탈퇴 사유 라디오 7종 (`기타(직접 작성)` 선택 시 최대 200자 입력창 필수)
- `"나중에 하기"` / `"탈퇴하기"` (`DELETE /api/auth/me` → 성공 시 `showWithdrawnPopup` 설정 + `signOut()` + `/` 이동)
