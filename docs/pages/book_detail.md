# 도서 상세 (`/book/[id]`)

> 파일: `app/book/[id]/page.tsx`, `app/book/[id]/BookDetailClient.tsx`, `components/BookReviewSection.tsx`
> 렌더링: **ISR (`revalidate = 3600`, 1시간)** + `dynamicParams = true` (빌드 시 상위 100권 정적 생성)

---

## 1. 현재 구현된 기능 (As-Is)

### 1-1. 상단 헤더 (`PageHeader`)
- 타이틀 `"도서 정보"`, `showHome=true` (뒤로가기 + 홈 버튼)
- 우측: 로그인 시 아바타(`/my-page`), 비로그인 시 유저 아이콘(`/auth/signup`)

### 1-2. 도서 기본 정보 영역 (모바일 1열 / 데스크톱 2열)
- **좌측 표지**: 3:4 비율 `next/image` (실패 시 원본 URL 폴백 → `BookOpen` 플레이스홀더)
  - *(참고: 도서 미리보기 버튼 및 `BookPreviewModal`은 현재 주석 처리되어 미노출)*
- **우측 메타 정보**:
  - **태그 칩 (최대 4개)**: `[메타 태그 1개(학년 우선, 없으면 연령)]` + `[비학년 큐레이션 태그 최대 3개]` (클릭 시 해당 큐레이션 목록 이동)
  - **제목(`h1`)**, **저자**, **출판사**
  - **전문 사서의 추천 포인트**: `curation_note`가 있을 때만 카드 노출
- **도서관 소장/대출 영역 (전국 1,600+ 공공도서관, 비로그인 전면 개방)**:
  - *도서관 선택됨*: `LibrarySelector`(전국 검색 + 내 주변 찾기) + **청구기호**(`callno[-vol]`, 신규 도서관은 단건 소장 확인 시 정보나루 `itemSrch` On-Demand 조회 + DB 자동 캐싱, 미제공 시 도서관 홈페이지 링크) + **실시간 대출 상태 배지**(`대출가능` 초록 / `대출중` 빨강 / `미소장` 회색 / `"확인중"` 시 배지 숨김) + `"정보가 다른가요? 제보하기"`(외부 구글 폼 새 창)
  - *도서관 미선택*: `"우리 동네 도서관에 지금 있을까?"` / `"전국 1,600+ 공공도서관 실시간 대출 확인"` CTA 행 → 클릭 시 로그인 없이 `LibrarySelector` 바텀시트 즉시 오픈
- **액션 버튼 행**:
  - **찜하기(Heart)**: 로그인 시 낙관적 업데이트, 비로그인 시 `LoginPromptModal` → 로그인 복귀 시 자동 찜 실행
  - **공유하기(Share2)**: `navigator.share` 우선, 미지원 시 클립보드 복사
  - **교보문고 구매 CTA**: `"도서관에 갈 시간이 없다면 / 지금 바로 주문하세요"` (ISBN 기반 LinkPrice 제휴 딥링크 새 탭)

### 1-3. 도서 소개
- `sanitizeDescriptionHtml(book.description)` 렌더링 (미등록 시 안내 문구)

### 1-4. 리뷰 섹션 (`BookReviewSection`)
- **평점 요약 카드**: 평균 별점, 총 평가 수, 득표수 상위 6개 키워드 뱃지
- **1-Tap 별점 입력**: 1~5점 별 버튼 (내 리뷰 미존재 시 작성 모달, 존재 시 수정 모달 오픈; 비로그인 시 로그인 유도 모달)
- **리뷰 리스트**: 기본 3건 노출 + `"리뷰 N개 더보기"` / `"접기"` 토글
  - 항목: 닉네임, 아이 나이, 별점, 상대 시간, 선택 뱃지 가로 스크롤, 한 줄 리뷰(`line-clamp-3`)
  - **내 리뷰 CRUD**: 작성 모달(별점 필수 + 뱃지 1~5개 필수 + 한 줄 리뷰 선택[입력 시 10~250자] + 아이 나이 선택), 카드 내 인라인 수정, 확인 모달 후 삭제

### 1-5. 하단 4단계 추천 슬라이더 (각 7권, 가로 스크롤)
1. **1번 슬롯 (`bg-muted-bg`)**: `"[대표태그] 책 추천 리스트"` + 더보기(`>`) (7권 미만 시 연령 인기 도서 폴백)
2. **2번 슬롯 (`bg-white`)**: `"또래 아이들이 많이 보는 [연령] 책 추천 리스트"` + 더보기(`>`)
3. **3번 슬롯 (`bg-muted-bg`)**: 대표 태그와 다른 AI 순수 주제 태그가 있을 때만 노출 — `"[주제태그] 책 추천 리스트"` + 더보기(`>`)
4. **4번 슬롯 (교차 배경)**: DB 내 동일 작가 다른 도서가 있을 때만 노출 — `"[작가명] 작가 추천 리스트"` (더보기 없음)

## 3. 정책 / 주의사항
- **`is_ai_generated` 배지 노출 금지**: 리뷰 영역에 AI 생성 여부 관련 UI를 절대 표시하지 않음.
- 태그 칩은 최대 4개(`메타 1 + 주제 최대 3`), 학년 태그가 있으면 포괄 연령 태그는 제외.
- ISR 캐시 누락 보완을 위해 로그인+도서관 선택 시 클라이언트에서 `book_library_info`를 5분 캐시로 재동기화.
