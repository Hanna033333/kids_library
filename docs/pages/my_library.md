# 내 책장 (`/my-library`)

> 파일: `app/my-library/page.tsx`
> 렌더링: Client Component (`'use client'`)

---

## 1. 현재 구현된 기능 (As-Is)

### 1-1. 상단 헤더 (`PageHeader`)
- 타이틀 `"내 책장"`, `showHome=true` (뒤로가기 + 홈 버튼)
- 우측: `ProfileDropdown` (클릭 시 `/my-page`)

### 1-2. 상단 요약 및 도서관 바
- 총 찜한 권수(`"총 N권"`)
- 선택 도서관에서 대출 가능한 도서가 1권 이상이면 `"대출 가능 N권"` 초록 배지 표시
- 우측: `LibrarySelector` (도서관 변경 시 실시간 대출 상태 자동 재조회)

### 1-3. 찜한 도서 목록 / 빈 상태
- **0권**: `"아직 책장에 꽂아둔 책이 없어요"` + `"책 보러 가기"`(`/`) 버튼
- **1권 이상**: 2/3/4열 그리드 `BookItem` (`showLibraryInfo=true`, `isSaved=true`)
  - 하트 클릭 시 낙관적 UI 업데이트로 즉시 목록에서 제거 (`unsaveBook`, 실패 시 롤백)
  - 실시간 대출 상태는 선택 도서관에 소장된 도서 ID만 추출해 비동기 배치 조회(목록 렌더링 블로킹 없음)

### 1-4. 목록 공유 플로팅 버튼 (FAB)
- 찜한 도서가 1권 이상일 때 우측 하단에 `"목록 공유"` 버튼(`Share2`) 노출
- 클릭 시 `[책자리] {도서관명} 목록 (N권)` + 번호별 `제목 - 청구기호 (대출상태)` + 링크 텍스트 생성 → `navigator.share` 또는 클립보드 복사 + 토스트

### 1-5. 비로그인 접근 처리
- 배경 전체 `blur-[3px] pointer-events-none` 처리 + `LoginPromptModal` 강제 노출
- 로그인 모달 닫기 시 홈(`/`)으로 이동
