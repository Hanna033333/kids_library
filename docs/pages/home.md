# 홈 (`/`)

> 파일: `app/page.tsx`, `components/HomePageClient.tsx`, `components/home/*`
> 렌더링: **ISR (`revalidate = 3600`, 1시간 캐시)** + 클라이언트 연령 맞춤 재정렬

---

## 1. 현재 구현된 기능 (As-Is)

### 1-1. 상단 헤더 (Sticky)
- 중앙: 책자리 로고 (`/logo.png`, 클릭 시 `/`)
- 우측: 검색 아이콘(`/books` 이동) + 프로필 아바타(로그인 시 `/my-page`, 비로그인 시 `/auth/signup`)
- *(참고: `LibrarySelector`는 현재 홈 헤더에서 주석 처리되어 미노출)*

### 1-2. 스포트라이트 배너 (`SpotlightBanner`)
- 3종 배너 **5초 자동 롤링** + 모바일 좌우 스와이프 + 일시정지/재생 & `< N / 3 >` 네비게이션
  1. `library` (앰버): `"도서관 가기 전 3초 / 지금 대출 가능할까?"` → `/my-library`
  2. `prescription` (퍼플): `"우리 아이 맞춤 / 그림책 처방전"` → `/collections`
  3. `textbook` (그린): `"초등 교과서 수록도서 / 학년별 필수 필독서"` → `/collections/curation/textbook`

### 1-3. AI 주간 동적 큐레이션 섹션 (`CurationSection` 반복)
- `shared/weekly_schedule.json`의 KST 날짜 구간 매칭(미매칭 시 7일 주기 결정론적 선택)
- 각 섹션은 2단 타이틀(서브 타이틀 위 / 메인 타이틀 아래) + `>` 더보기 링크 + 가로 스크롤 슬라이더(7권)
- 배경색: `bg-white` ↔ `bg-muted-bg` 교차 배치
- 각 카드(`BookCard`)는 해당 섹션 대표 태그(`excludeTag`)를 하단 태그에서 제외

### 1-4. 50+ 전문 테마 큐레이션 쇼케이스 (`ThemeCurationShowcase`)
- 타이틀: `"우리 아이 맞춤 그림책 처방전"`
- 가로 스크롤 탭 7종: `초록 지구·환경`, `잠자리·수면`, `정겨운 명절`, `상실과 위로`, `상상·창의력`, `우리 문화 유산`, `다름과 존중` + 우측 끝 전체 보기 `>` (`/collections`)
- 탭 클릭 시 해당 태그 도서 14권 조회(클라이언트 캐싱) 후 7권 노출, PC에서 좌/우 스크롤 화살표 제공
- 하단 링크: `"{탭명} 관련 도서 전체보기 >"`

### 1-5. 교과서 수록도서 쇼케이스 (`TextbookCurationShowcase`)
- 타이틀: `"교과서 수록도서"` (2022 개정)
- 학년 탭 7종: `전체`, `초등 1학년` ~ `초등 6학년`
- **2단(2행 × N열) 가로형 카드** 슬라이더로 최대 6권 노출 (좌측 썸네일 + 우측 제목/태그 2개)
- 하단 링크: `"{탭명} 교과서 수록도서 전체보기 >"` (`/books?curation=교과서수록[&tag=초등N학년]`)

### 1-6. 고정/시즌 큐레이션 섹션 (`CurationSection`)
- **칼데콧 수상작** → `/books?curation=caldecott`
- **2026 여름방학 추천도서** (조건부: KST `2026-08-20` 이하 & 도서 1권 이상일 때만 노출)
- **어린이도서연구회 추천** → `/books?curation=research-council`
- *(겨울방학 섹션은 현재 주석 처리)*

### 1-7. 하단 공지사항 바 & 푸터
- `shared/latest_notice.json` 기반 최신 공지 1건 노출 (클릭 시 Notion 공지 새 창)
- `Footer`

### 1-8. 로그인/세션 기반 동작
- **선호 연령 맞춤 재정렬**: 로그인 + `preferredChildAge` 설정 시, **교과서 수록도서를 제외한** 모든 큐레이션을 선호 연령 우선으로 클라이언트 재정렬해 7권 노출
- **도서관/찜 UI 미노출**: 홈 도서 카드에서는 청구기호, 대출 배지, 찜 하트를 표시하지 않음
- **세션 플래그 피드백**: 회원 탈퇴 완료 시 `ConfirmModal`, 로그아웃 직후 `Toast` 노출

### 1-9. 현재 미사용(보존) 컴포넌트
- `MainBanner.tsx`: `SpotlightBanner`로 대체되어 현재 미사용
- `SearchDiscoveryHub.tsx`: 실시간 인기 검색어 Top 10 / 상황별 추천 키워드 컴포넌트(현재 홈 미배치)

## 3. 정책 / 주의사항
- **7-Book Rule**: 도서가 7권 미만인 `CurationSection`은 화면에 렌더링하지 않음.
- **표지 이미지 필수**: 유효 표지가 없거나 알라딘 `noimg`인 도서는 홈에 노출 금지.
- **이모티콘 금지**: 홈의 모든 큐레이션 타이틀에는 이모지를 넣지 않고 순수 텍스트만 사용.
- **TTFB 최적화**: 홈 서버 쿼리에서는 도서관 소장 정보 조인을 생략(`includeLibraryInfo = false`).
